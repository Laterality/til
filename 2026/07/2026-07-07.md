## 개요

### Kubernetes의 객체

#### Kubernetes 객체 관리

##### 명령적 커맨드

명령적 커맨드슬 사용할 때 사용자는 클러스터에 살아있는 객체에 직접 작업한다. 사용자는 `kubectl` 명령에 작업을 인자나 플래그로 전달한다.

처음 시작하거나 클러스터에서 일회성 작업을 실행할 때 권장되는 방법이다. 이 기법은 살아있는 객체에 직접 작업하기 때문에, 이력이나 이전 구성을 제공하지 않는다.

##### 예시

디플로이먼트 객체를 생성해 nginx 컨테이너 인스턴스를 생성한다:

```bash
kubectl create deployment nginx --image nginx
```

##### 트레이드 오프

객체 구성과 비교한 이점:

- 커맨드가 단일 행위 단어로 표현된다.
- 커맨드는 클러스터에 변경을 가하는 데 한 단계만 거친다.

객체 구성과 비교한 단점:

- 커맨드가 검토 과정에 통갑되지 않는다.
- 커맨드가 감사(audit) 추적 관련 변경을 제공하지 않는다.
- 커맨드가 살아있는 객체 외에는 기록의 원천을 제공하지 않는다.
- 커맨드가 새 객체를 만들기 위한 템플릿을 제공하지 않는다.
