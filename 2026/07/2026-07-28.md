### Kubernetes의 객체

#### 라벨과 선택자

##### 라벨 갱신하기

때로는 새 리소스를 만들기 전에 기존 파드나 다른 리소스를 재라벨링하고자 할 때가 있다. `kubectl label`을 사용할 수 있다. 예를 들어, 모든 NGINX 파드를 forntend tier로 라벨링할 때는 다음처럼 실행한다:

```bash
kubectl label pods -l app=nginx tier=fe
```

```plaintext
pod/my-nginx-2035384211-j5fhi labeled
pod/my-nginx-2035384211-u2c7e labeled
pod/my-nginx-2035384211-u3t6x labeled
```

이는 먼저 파드를 라벨 "app=nginx"로 필터링한 다음, "tier=fe"로 라벨링한다. 라벨링한 파드를 보려면 다음을 실행한다:

```bash
kubectl get pods -l app=nginx -L tier
```

```plaintext
NAME                        READY     STATUS    RESTARTS   AGE       TIER
my-nginx-2035384211-j5fhi   1/1       Running   0          23m       fe
my-nginx-2035384211-u2c7e   1/1       Running   0          23m       fe
my-nginx-2035384211-u3t6x   1/1       Running   0          23m       fe
```

모든 "app=nginx" 파드를 출력하고 추가로 파드의 tier(`-L` 혹은 `--label-columns`로 명시)를 라벨 칼럼으로 사용한다.

더 자세한 정보는 [kubectl label][k8s-reference-generated-kubectl-kubectl-command-label]을 참고하라.

[k8s-reference-generated-kubectl-kubectl-command-label]: https://kubernetes.io/docs/reference/generated/kubectl/kubectl-commands#label
