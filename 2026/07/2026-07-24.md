### Kubernetes의 객체

#### 라벨과 선택자

##### API

###### API 객체에 레퍼런스 설정

[`services`][k8s-concepts-services-networking-service]와 [`replicationcontrollers`][k8s-concepts-workloads-controllers-replicationcontroller]와 같은 일부 Kubernetes 객체는 라벨 선택자를 사용해 [파드][k8s-workloads-pods]와 같은 다른 리소스 집합을 명시하기도 한다.

**Service와 ReplicationController**

`service`가 대상으로 하는 파드 집합은 라벨 선택자로 정의된다. 비슷하게, `replicationcontroller`가 관리해야 하는 파드 집단도 라벨 선택자로 정의된다.

두 객체를 위한 라벨 선택자는 `json` 또는 `yaml` 파일에 맵을 사용해 정의되며 *동등성-기반* 요구사항 선택자만 지원된다:

```json
"selector": {
    "component" : "redis",
}
```

혹은

```yaml
selector:
  component: redis
```

이 선택자는(`json`과 `yaml` 형식 각각) `component=redis` 또는 `component in (redis)`와 동등하다.
