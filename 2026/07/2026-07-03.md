## 개요

### Kubernetes의 객체

#### 서버 측 필드 검증

Kubernetes v1.25부터 API 서버는 객체에서 인지할 수 없거나 중복된 필드를 탐지하는 서버 측 [필드 검증][k8s-reference-using-api-api-concepts-field-validation]을 제공한다. `kubectl --validate`의 모든 기능을 서버 측에서 제공한다.

`kubectl` 도구는 `--validate` 플래그를 사용해 필드 검증의 수준을 설정한다. `ignore`, `warn`, `strict` 값과 (`strict`와 동등한) `true`와 (`ignore`와 동등한) `false`도 수용한다. `kubectl`의 기본 검증 설정은 `--validate=true`다.

- `Strict`: 엄격한 필드 검증, 검증 실패시 오류 발생
- `Warn`: 필드 검증을 수행하지만 오류는 요청 실패 대신 경고를 노출
- `Ignore`: 서버 측 필드 검증 수행하지 않음

`kubectl`이 필드 검증을 지원하는 API 서버에 연결할 수 없으면 클라이언트 측 검증으로 전환한다. Kubernetes 1.27과 그 이후 버전들은 항상 필드 검증을 제공한다. 이전 버전의 Kubernetes 릴리즈들은 아닐 수 있다. 클러스터가 v1.27 이전 버전이라면 해당 버전의 Kubernetes 문서를 확인하라.

[k8s-reference-using-api-api-concepts-field-validation]: https://kubernetes.io/docs/reference/using-api/api-concepts/#field-validation
