## 개요

### Kubernetes의 객체

#### 라벨과 선택자

*라벨*은 파드와 같은 객체에 추가되는(attached) 키/값 쌍이다. 라벨은 사용자에게 의미있고 관련이 있지만, 코어 시스템에는 직접적인 의미가 없는 객체 식별 속성을 지정하는 데 쓰인다. 라벨은 객체의 하위 집합을 조직하고 선택하는 데 사용할 수 있다. 사벨은 객체 생성 시점에 추가할 수 있고 그 후 언제든 더하거나 수정할 수 있다. 각 객체는 정의된 키/값 라벨 집합을 가질 수 있다. 각 키는 주어진 객체에서 유일해야 한다.

```json
"metadata": {
  "labels": {
    "key1" : "value1",
    "key2" : "value2"
  }
}
```

라벨은 효율적인 쿼리와 감시(watch)를 가능케 하고 UI와 CLI에서 사용하기에 이상적이다. 비 식별 정보는 [어노테이션][k8s-concepts-overview-working-with-objects-annotations]을 사용하는 것이 좋다.

[k8s-concepts-overview-working-with-objects-annotations]: https://kubernetes.io/docs/concepts/overview/working-with-objects/annotations/
