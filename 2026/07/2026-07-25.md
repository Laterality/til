###### API 객체에 레퍼런스 설정

**집합-기반 요구사항을 지원하는 리소스**

[`Job`][k8s-concepts-workloads-controllers-job], [`Deployment`][k8s-concepts-workloads-controllers-deployment], [`ReplicaSet`][k8s-concepts-workloads-controllers-replicaset], [`DaemonSet`][k8s-concepts-workloads-controllers-daemonset]과 같은 보다 최신 리소스들은 *집합-기반* 요구사항도 지원한다.

```yaml
selector:
  matchLabels:
    component: redis
  matchExpressions:
    - { key: tier, operator: In, values: [cache] }
    - { key: environment, operator: NotIn, values: [dev] }
```

`matchLabel`은 `{key,value}` 쌍의 맵이다. `matchLabel` 맵에서 하나의 `{key,value}`는 `matchExpression`에서 `key`가 "key"이고 `operator`가 "in"이고 `values`가 "value"만 갖는 요소와 동등하다. `matchExpressions`는 파드 선택자 요구사항의 목록이다. 유효한 연산자는 in, NotIn, Exists, DoesNotExist다. NotIn의 경우 값 집합은 비어있을 수 없다. `matchLabels`와 `matchExpressions` 양쪽 모두에서 요구사항들은 AND 연산된다. 즉, 순서대로 모두 일치해야 한다.
