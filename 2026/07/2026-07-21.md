##### 라벨 선택자

###### *동등성-기반* 요구사항

*동등성-* 혹은 *비동등성-기반* 요구사항은 라벨 키와 값을 필터링할 수 있게 한다. 일치시키는 객체는 지정된 라벨 제약을 모두 만족해야 하지만 라벨을 추가로 가질 수 있다. 세 종류의 연산자 `=`, `==`, `!=`가 허용된다. 처음 두 개는 *동등성*(및 유의어)을, 나머지 하나는 *비동등성*을 나타낸다. 예시:

```
environment = production
tier != frontend
```

전자는 키가 `environment`이고 값이 `production`과 같은 모든 리소스를 선택한다. 후자는 키가 `tier`와 같고 값이 `frontend`가 아닌 모든 리소스와 `tier`가 키인 라벨이 없는 모든 리소스를 선택한다. 쉼표 연산자를 사용해 `frontend`를 제외한 `production` 리소스를 필터링하는 경우: `environment=production,ftier!=frontend`

동등성 기반 요구사항의 한 가지 사용 시나리오는 파드에 노드 선택 술어를 명시하는 것이다. 예를 들어, 아래의 샘플 파드는 `accelerator` 라벨이 존재하고 `nvidia-telsa-p100`으로 설정된 노드를 선택한다.

```yaml
apiVersion: v1
kind: Pod
metadata:
  name: cuda-test
spec:
  containers:
    - name: cuda-test
      image: "registry.k8s.io/cuda-vector-add:v0.1"
      resources:
        limits:
          nvidia.com/gpu: 1
  nodeSelector:
    accelerator: nvidia-tesla-p100
```
