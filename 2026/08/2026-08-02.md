###### 요청에 네임스페이스 설정

현재 요청에 네임스페이스를 설정하려면 `--namespace` 플래그를 사용한다.

예를 들어:

```bash
kubectl run nginx --image=nginx --namespace=<insert-namespace-name-here>
kubectl get pods --namespace=<insert-namespace-name-here>
```
