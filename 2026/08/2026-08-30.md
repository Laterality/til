## 개요

### Kubernetes의 객체

#### 스토리지 버전

##### 스토리지 버전이 암호화와 어떻게 관련 있는가

클러스터의 [rest 스토리지][k8s-tasks-administer-cluster-kms-provider]에서 특히 클러스터 시크릿을 암호화하는 도구들이 있다. 이는 클러스터에 실제로 저장된 데이터가 암호화되므로 데이터 유출에 추가적인 보호 계층을 더한다. 즉, API 서버는 스토리지에서 데이터를 조회할 때 복호화한다. API 서버는 객체를 적절하게 디코딩하려면 스토리지 버전에 맞는 키를 가지고 있어야 한다.

이 경우 스토리지 버전은 객체의 바이너리 인코딩 그 이상이다. 저장된 것이 어떻게든 API 객체로 변환될 수 있는 한, 스토리지 버전으로 사용될 수 있다.

[k8s-tasks-administer-cluster-kms-provider]: https://kubernetes.io/docs/tasks/administer-cluster/kms-provider/
