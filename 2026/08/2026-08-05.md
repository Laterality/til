## 개요

### Kubernetes의 객체

#### 네임스페이스

##### 모든 객체가 네임스페이스에 있지는 않다

대부분의 Kubernetes 객체(e.g., Pod, Service, Deployment 등)는 어떤 네임스페이스에 있다. 하지만 네임스페이스 리소스는 그 자체로 네임스페이스에 속하지 않는다. [Node][k8s-concepts-architecture-nodes]와 [PersistentVolumes][k8s-concepts-storage-persistent-volumes]와 같은 하위 수준 리소스는 어떤 네임스페이스에도 속하지 않는다.

네임스페이스에 속하지 않은 Kubernetes 리소스를 보려면:

```bash
# In a namespace
kubectl api-resources --namespaced=true

# Not in a namespace
kubectl api-resources --namespaced=false
```

[k8s-concepts-architecture-nodes]: https://kubernetes.io/docs/concepts/architecture/nodes/
[k8s-concepts-storage-persistent-volumes]: https://kubernetes.io/docs/concepts/storage/persistent-volumes/
