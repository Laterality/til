## 개요

### Kubernetes의 객체

#### 스토리지 버전

##### 스토리지 버전을 리소스로 매핑

모든 리소스는 어느 시점에든 하나의 활성 스토리지 버전을 갖는다. 즉, 한 객체에 대한 쓰기는 그 스토리지 버전으로 객체를 저장한다. 하지만 스토리지 버전은 갱신될 수 있어 객체들이 서로 다른 버전들로 저장될  수 있다. 하나의 객체는 어느 시점에든 하나의 스토리지 버전으로만 저장된다.

API 서버로부터의 읽기는 저장된 데이터를 객체의 API 표현으로 변환한다. 객체에 대한 갱신이 발생하지 않는 한 오래된 스토리지 버전을 계속 사용하게 된다. 반면에 쓰기는 갱신시 저장된 버전을 새 표현으로 변환한다.
