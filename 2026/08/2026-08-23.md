## 개요

### Kubernetes의 객체

#### 권장 라벨

##### 라벨

이 라벨을 사용했을 때의 이점을 온전히 누리려면 모든 리소스 객체에 적용돼야 한다.

| 키                             | 설명                                                                      | 예시           | 타입   |
| ------------------------------ | ------------------------------------------------------------------------- | -------------- | ------ |
| `app.kubernetes.io/name`       | 애플리케이션 이름                                                         | `mysql`        | string |
| `app.kubernetes.io/instance`   | 애플리케이션 인스턴스를 식별하는 고유한 이름                              | `mysql-abcxyz` | string |
| `app.kubernetes.io/version`    | 애플리케이션의 현재 버전(e.g., [SemVer 1.0][semver-1-0], 리비전 해시 등`) | `5.7.21`       | string |
| `app.kubrenetes.component`     | 아키텍처 내의 구성요소                                                    | `database`     | string |
| `app.kubernetes.io/part-of`    | 이 애플리케이션이 구성하는 보다 상위 수준의 애플리케이션 이름             | `Wordpress`    | string |
| `app.kubernetes.io/managed-by` | 애플리케이션 운영을 관리하는데 쓰이는 도구                                | `Helm`         | string |

다음 [StatefulSet][k8s-concepts-workloads-controller-statefulset] 객체는 이 라벨들을 어떻게 사용하는지 보여준다:

```yaml
# This is an excerpt
apiVersion: apps/v1
kind: StatefulSet
metadata:
  labels:
    app.kubernetes.io/name: mysql
    app.kubernetes.io/instance: mysql-abcxyz
    app.kubernetes.io/version: "5.7.21"
    app.kubernetes.io/component: database
    app.kubernetes.io/part-of: wordpress
    app.kubernetes.io/managed-by: Helm
```
