###### 데이터베이스를 사용하는 웹 애플리케이션

약간 더 복잡한 애플리케이션을 생각해보자. Helm을 사용해 설치된 데이터베이스(MySQL)을 사용하는 웹 애플리케이션(WordPress)이다. 다음 스니펫은 이 애플리케이션을 배포하는 데 쓰인 객체의 시작 부분이다.

WordPress에 쓰인 `Deployment`:

```yaml
apiVersion: apps/v1
kind: Deployment
metadata:
  labels:
    app.kubernetes.io/name: wordpress
    app.kubernetes.io/instance: wordpress-abcxyz
    app.kubernetes.io/version: "4.9.4"
    app.kubernetes.io/managed-by: Helm
    app.kubernetes.io/component: server
    app.kubernetes.io/part-of: wordpress
...
```

WordPress를 노출하는 데 쓰인 `Service`:

```yaml
apiVersion: v1
kind: Service
metadata:
  labels:
    app.kubernetes.io/name: wordpress
    app.kubernetes.io/instance: wordpress-abcxyz
    app.kubernetes.io/version: "4.9.4"
    app.kubernetes.io/managed-by: Helm
    app.kubernetes.io/component: server
    app.kubernetes.io/part-of: wordpress
...
```

MySQL은 자신과 자신이 속한 더 큰 애플리케이션에 대한 메타데이터와 함께 `StatefulSet`으로 노출된다:

```yaml
apiVersion: apps/v1
kind: StatefulSet
metadata:
  labels:
    app.kubernetes.io/name: mysql
    app.kubernetes.io/instance: mysql-abcxyz
    app.kubernetes.io/version: "5.7.21"
    app.kubernetes.io/managed-by: Helm
    app.kubernetes.io/component: database
    app.kubernetes.io/part-of: wordpress
...
```

`Service`는 WordPress의 일부로 MySQL을 노출하는 데 쓰인다:

```yaml
apiVersion: v1
kind: Service
metadata:
  labels:
    app.kubernetes.io/name: mysql
    app.kubernetes.io/instance: mysql-abcxyz
    app.kubernetes.io/version: "5.7.21"
    app.kubernetes.io/managed-by: Helm
    app.kubernetes.io/component: database
    app.kubernetes.io/part-of: wordpress
...
```

MySQL `StatefulSet`과 `Service`를 사용해 더 넓은 애플리케이션인 MySQL과 WordPress에 대한 정보를 알 수 있다.
