## 개요

### Kubernetes API

#### OpenAPI 인터페이스 정의

OpenAPI 명세에 관한 자세한 내용은 [OpenAPI 문서][openapi]를 참고하라.

Kubernetes는 OpenAPI v2.0과 OpenAPI v3.0을 둘 다 제공한다. OepnAPI v3가 더 (손실 없이)포괄적인 Kubernetes 리소스 표현을 제공하기 때문에 OpenAPI 접근시 선호되는 방법이다. OpenAPI v2의 한계로 인해 `default`, `nullable`, `oneOf`에 국한되지 않고 특정 필드는 게시된 OpenAPI에서 버려진다.

[openapi]: https://www.openapis.org/
