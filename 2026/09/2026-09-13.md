## 개요

### kubectl 커맨드 라인 도구

#### kubectl의 역할

`kubectl` 도구는 Kubernetes 객체를 생성, 조사, 갱신, 삭제하는 주요 인터페이스다. 클러스터 내에서 실행되는 [Kubernetes 구성 요소][k8s-concepts-overview-components]와 구성 요소들이 구현하는 [Kubernetes API][k8s-concepts-overview-kubernetes-api]를 보완한다. 램탑이나 클러스터 내의 Pod에서 `kubectl`을 실행하면 API 서버로 요청을 보낸다. [클라이언트 라이브러리][k8s-reference-using-api-client-libraries]와 [Headlamp][headlamp] 같은 웹 대시보드같은 다른 클라이언트도 같은 API를 통해 통신한다.
