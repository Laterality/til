## 개요

### Kubernetes API

#### 디스커버리 API

##### 집계되지 않은 디스커버리

디스커버리 집계가 없으면 다운스트림 문서들에 대한 디스커버리 정보를 게시하는 루트 엔드포인트와 함께 디스커버리가 레벨 별로 게시된다.

클러스터가 지원하는 모든 그룹 버전 목록은 `/api`와 `/apis` 엔드포인트에 게시된다. 예시:

```json
{
  "kind": "APIGroupList",
  "apiVersion": "v1",
  "groups": [
    {
      "name": "apiregistration.k8s.io",
      "versions": [
        {
          "groupVersion": "apiregistration.k8s.io/v1",
          "version": "v1"
        }
      ],
      "preferredVersion": {
        "groupVersion": "apiregistration.k8s.io/v1",
        "version": "v1"
      }
    },
    {
      "name": "apps",
      "versions": [
        {
          "groupVersion": "apps/v1",
          "version": "v1"
        }
      ],
      "preferredVersion": {
        "groupVersion": "apps/v1",
        "version": "v1"
      }
    },
    ...
}
```

각 그룹 버전에 대한 디스커버리 문서를 얻으려면 특정 그룹 버전 하위에 제공되는 리소스 목록을 광고하는 `/apis/<group>/<version>`(예시: `/apis/rbac.authorization.k8s.io/v1alpha1`)에 추가 요청이 필요하다. 이 엔드포인트들은 kubectl이 클러스터가 지원하는 리소스 목록을 인출하는 데 사용한다.
