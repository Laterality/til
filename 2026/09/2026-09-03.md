## 개요

### Kubernetes API

#### 디스커버리 API

##### 집계된 디스커버리

*Kubernetes에서 1.30 릴리즈부터 안정적인 기능이다. 이 기능은 더이상 기능 플래그로 토글할 수 없다(관련된 [기능 게이트][k8s-reference-command-line-tools-reference-feature-gates-removed]는 제거됐다).

Kubernetes는 클러스터가 두 엔드포인트(`/api`와 `/apis`)를 통해 지원하는 모든 리소스를 게시해 *집계된 디스커버리*를 안정적으로 지원한다. 이 엔드포인트를 요청하면 클러스터에서 디스커버리 데이터를 인출하기 위해 보내야 하는 요청의 수를 크게 줄일 수 있다. 집계된 디스커버리 리소스를 나타내는 `Accept` 헤더(`Accept: application/json;v=v2;g=apidiscovery.k8s.io;as=APIGroupDiscoveryList`)와 함께 각 엔드포인트에 요청해 데이터에 접근할 수 있다.

`Accept` 헤더를 사용해 리소스 유형을 나타내지 않으면 `/api`와 `/apis` 엔드포인트에 대한 기본 응답은 집계되지 않은 디스커버리 문서가 된다.

내장 리소스의 [디스커버리 문서][github-k8s-release-1-37-api-discovery-aggregated-v2]는 Kubernetes GitHub 저장소에서 찾을 수 있다. 이 GitHub 문서는 Kubernetes 클러스터에 쿼리할 수 없을 때 사용 가능한 리소스의 기본 집합의 레퍼런스로 쓰일 수 있다.

엔드포인트는 ETag와 protobuf 인코딩도 지원한다.
