## 개요

### Kubernetes API

#### 디스커버리 API

Kubernetes는 디스버리 API를 통해 지원되는 모든 그룹 버전들과 리소스 목록을 게시한다. 여기에는 각 리소스에 대한 다음 내용이 포함된다:

- 이름
- 클러스터나 네임스페이스를 갖는 범위
- 엔드포인트 URL과 지원되는 행위(verb)
- 대체 이름(alternative names)
- 그룹, 버전, 유형(kind)

API는 집계된(aggregated) 형태와 집계되지 않은(unaggregated) 형태 둘 다로 사용할 수 있다. 집계된 디스커버리는 두 엔드포인트를 제공하고 집계되지 않은 디스커버리는 각 그룹 버전별로 개별 엔드포인트를 제공한다.
