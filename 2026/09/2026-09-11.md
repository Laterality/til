## 개요

### Kubernetes API

#### API 확장

Kubernetes API는 둘 중 한가지 방법으로 확장할 수 있다:

1. [커스텀 리소스][k8s-concepts-extend-kubernetes-api-extension-custom-resources]는 선택된 리소스 API를 API 서버가 어떻게 제공해야 하는지를 정의한다.
2. [집계 계층][k8s-concepts-extend-kubernetes-api-extension-apiserver-aggregation]을 구현해 Kubernetes API를 확장할 수도 있다.
