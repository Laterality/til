## 개요

### Kubernetes API

#### OpenAPI 인터페이스 정의

##### OpenAPI V2

Kubernetes API 서버는 `/openapi/v2` 엔드포인트를 통해 집계된 OpenAPI v2 명세를 제공한다. 다음과 같이 요청 헤더를 사용해 응답 형식을 요청할 수 있다:

<table>
<thead>
<tr>
<th>헤더</th>
<th>사용 가능한 값</th>
<th>참고</th>
</tr>
</thead>
<tbody>
<tr>
<td><code>Accept-Encoding</code></td>
<td><code>gzip</code></td>
<td><i>이 헤더는 전달하지 않아도 된다</i></td>
</tr>
<tr>
<td rowspan="3"><code>Accept</code></td>
<td><code>application/com.github.proto--openapi.spec.v2@v1.0+protobuf</code></td>
<td><i>주로 클러스터간 사용을 위한 것이다</i></td>
</tr>
<tr>
<td><code>application/json</code></td>
<td><i>기본값</i></td>
</tr>
<tr>
<td><code>*</code></td>
<td><i><code>application/json</code>를 제공한다</i></td>
</tr>
</tbody>
</table>

> [!WARNING]
>
> OpenAPI 스키마의 일부로 게시된 유효성 검사 규칙은 완전하지 않을 수 있으며 대부분 그렇다. API 서버에서 추가적인 유효성 검사가 이뤄진다. 정확하고 완전한 검증을 알고 싶다면 `kubectl apply --dry-run=server`가 적용 가능한 모든 유효성 검사를 실행(하고 승인 시점 검사도)한다.
