## 클러스터 아키텍처

### 컨트롤 플레인 구성 요소

#### kube-apiserver

API 서버는 Kubernetes API를 노출하는 Kubernetes [컨트롤 플레인][k8s-reference-glossary]의 구성 요소다. API 서버는 Kubernetes 컨트롤 플레인의 프론트 엔드다.

Kubernetes API 서버의 주요 구현체가 [kube-apiserver][k8s-reference-command-line-tools-reference-kube-apiserver]다. kube-apiserver는 수평적으로 확장 가능하도록 설계됐다. 즉, 더 많은 인스턴스를 배포해 확장한다. 몇 개의 kube-apiserver 인스턴스를 실행하고 이 인스턴스들 사이에 트래픽을 분배할 수 있다.
