## 개요

### Kubernetes API

#### OpenAPI 인터페이스 정의

##### OpenAPI V3

*Kubernetes 1.27부터 안정화된 기능이다. 더이상 기능을 토글할 수 없다.*

Kubernetes OpenAPI v3로 API 설명을 게시할 수 있다.

디스커버리 엔드포인트 `/openapi/v3`는 사용 가능한 모든 그룹/버전 목록을 볼 수 있다. 이 엔드포인트는 JSON만 반환한다. 이 그룹/버전들을 다음 형식으로 제공된다:

```json
{
    "paths": {
        ...,
        "api/v1": {
            "serverRelativeURL": "/openapi/v3/api/v1?hash=CC0E9BFD992D8C59AEC98A1E2336F899E8318D3CF4C68944C3DEC640AF5AB52D864AC50DAA8D145B3494F75FA3CFF939FCBDDA431DAD3CA79738B297795818CF"
        },
        "apis/admissionregistration.k8s.io/v1": {
            "serverRelativeURL": "/openapi/v3/apis/admissionregistration.k8s.io/v1?hash=E19CC93A116982CE5422FC42B590A8AFAD92CDE9AE4D59B5CAAD568F083AD07946E6CB5817531680BCE6E215C16973CD39003B0425F3477CFD854E89A9DB6597"
        },
        ....
    }
}
```

상대 URL들은 클라이언트 측 캐싱을 향상시키기 위한 불변 OpenAPI 설명을 가리킨다. 이를 위해 API 서버는 적절한 HTTP 캐싱 헤더를 설정한다(`Expires`는 1년이며 `Cache-Control`은 `immutable`이다). 폐기된(obsolete) URL이 사용되면 API 서버는 최신 URL로 리다이렉트시킨다.

Kubernetes API 서버는 `/openapi/v3/apis/<group>/<version>?hash=<hash>` 엔드포인트에서 Kubernetes 그룹 버전 별 OpenAPI v3 명세를 게시한다.

OpenAPI V3를 인출하는 Golang 구현체는 [`k8s.io/client-go/openapi3`][pkg-go-k8s-io-client-go-openapi-3] 패키지에 제공된다.

Kubernetes 1.37은 OpenAPI v2.0과 v3.0을 게시한다. 가까운 시일에 3.1을 지원할 계획은 없다.

[pkg-go-k8s-io-client-go-openapi-3]: https://pkg.go.dev/k8s.io/client-go/openapi3
