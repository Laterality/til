## 클러스터 아키텍처

### 노드와 컨트롤 플레인 사이의 통신

#### 컨트롤 플레인에서 노드로

##### API 서버에서 kubelet으로

API 서버에서 kubelet으로의 연결은 다음의 경우에 사용된다:

- 파드의 로그 인출
- (주로 `kubectl`을 통해)실행중인 파드에 부착(attach)
- kubelet의 포트 포워딩 기능 제공

이 연결은 kubelet의 HTTPS 엔드포인트에서 끝난다. 기본적으로, API 서버는 kubelet의 서버 인증서를 확인하지 않아 이 연결은 중간자 공격의 대상이 되고 실회할 수 없거나 공개된 네트워크에서 실행하는 것은 **안전하지 않다**.

이 연결을 확인하려면 kubelet이 제공하는 인증서를 확인하는 데 사용할 루트 인증서 번들과 함께 `--kubelet-certificate-authority` 플래그를 API 서버에 제공하라.

이것이 불가능한 경우 신뢰할 수 없거나 공개된 네트워크를 통한 연결을 피해야 한다면 API 서버와 kubelet 사이에 [SSH 터널링][k8s-concepts-architecture-control-plane-node-communication-ssh-tunnels]을 사용하라.

마지막으로, [kubelet 인증 및 인가][k8s-reference-access-authn-authz-kubelet-authn-authz]를 활성화해 kubelet API를 보호하라.
