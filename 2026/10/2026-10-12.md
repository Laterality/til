## 클러스터 아키텍처

### 노드

#### 관리

[API 서버][k8s-concepts-architecture-kube-apiserver]에 노드를 추가하는 방법은 두 가지가 있다:

1. 노드의 kubelet이 컨트롤 플레인에 직접 등록
2. 여러분(이나 다른 인간 사용자)가 Node 객체를 수동으로 추가

Node [객체][k8s-concepts-overview-working-with-objects-kubernetes-objects]를 만들거난 노드의 kubelet이 직접 등록하고 나면, 컨트롤 플레인은 새 Node 객체가 유효한지 검사한다. 예를 들어, 다음 JSON 매니페스트로 Node를 만들려고 하면:

```json
{
  "kind": "Node",
  "apiVersion": "v1",
  "metadata": {
    "name": "10.240.79.157",
    "labels": {
      "name": "my-first-k8s-node"
    }
  }
}
```

Kubernetes는 내부적으로 Node 객체(표현)을 생성한다. Kubernetes는 Node의 `metadata.name` 필드가 일치하는 kubelet이 API 서버에 등록됐는지 확인한다. 노드가 건강(healthy)하면(i.e. 모든 필수 서비스가 실행중이면) Pod를 실행할 수 있다. 그렇지 않으면 노드가 건강한 상태가 될 때까지 모든 클러스터 활동에서 무시된다.

> [!NOTE]
>
> Kubernetes는 유효하지 않은 Node를 위한 객체를 유지하고 건강한 상태가 될 때까지 계속 검사한다.
>
> 이 헬스 체크를 멈추려면 여러분이나 [컨트롤러][k8s-concepts-architecture-controller]가 명시적으로 Node 객체를 제거해야 한다.

Node의 이름은 유효한 [DNS 서브도메인 이름][k8s-concepts-overview-working-with-objects-names-dns-subdomain-names]이어야 한다.
