## 클러스터 아키텍처

### 노드와 컨트롤 플레인 사이의 통신

#### 컨트롤 플레인에서 노드로

##### API 서버에서 노드, 파드, 서비스로

API 서버에서 노드, 파드, 혹은 서비스로의 연결은 기본적으로 평범한 HTTP 커넥션이기 때문에 인증되거나 암호화되지 않는다. API URL의 노드, 파드, 서비스 이름에 `https:` 접두어를 추가해 안전한 HTTPS 연결로 실행할 수 있지만, HTTPS 엔드포인트에서 제공한 인증서를 검증하거나 클라이언트 크리덴셜을 제공하지는 않는다. 따라서 커넥션은 암호화되지만 어떠한 무결성도 보장하지 않는다. 이 연결은 신뢰할 수 없거나 공개된 네트워크에서 실행하기에는 **현재 안전하지 않다**.
