## 클러스터 아키텍처

### 노드와 컨트롤 플레인 사이의 통신

#### 컨트롤 플레인에서 노드로

컨트롤 플레인(API 서버)에서 노드로 향하는 통신 경로는 크게 두 가지가 있다. 첫 번째는 API 서버에서 클러스터의 각 노드에서 실행중인 [kubelet][k8s-reference-command-line-tools-reference-kubelet] 프로세스로 향하는 것이다. 두 번째는 API 서버의 *프록시* 기능을 통해 API 서버에서 모든 노드, 파드, 서비스로 향하는 것이다.

[k8s-reference-command-line-tools-reference-kubelet]: https://kubernetes.io/docs/reference/command-line-tools-reference/kubelet/
