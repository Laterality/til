## 클러스터 아키텍처

### 클라우드 컨트롤러 매니저

#### 인가(Authorization)

이 섹션에서는 클라우드 컨트롤러 매니저가 다양한 API 객체에 작업을 수행하기 위해 필요한 접근을 살펴본다.

##### Node 컨트롤러

Node 컨트롤러는 Node 객체만 작업한다. Node 객체에 대한 완전한 읽기와 변경 접근이 필요하다.

`v1/Node`:

- get
- list
- create
- update
- patch
- watch
- delete
