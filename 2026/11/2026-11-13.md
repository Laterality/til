## 클러스터 아키텍처

### 클라우드 컨트롤러 매니저

#### 클라우드 컨트롤러 매니저 기능

##### Node 컨트롤러

노드 컨트롤러는 클라우드 인프라스트럭처에 새 서버가 만들어지면 [Node][k8s-concepts-arhictecture-nodes] 객체를 갱신할 책임을 갖는다. 노드 컨트롤러는 클라우드 제공자로부터 테넌시에서 실행중인 호스트에 대한 정보를 얻는다. 노드 컨트롤러는 다음 기능을 수행한다:

1. Node 객체를 클라우드 제공자 API로부터 얻은 해당하는 서버의 유일한 식별자로 갱신한다.
2. Node 객체에 노드가 배포된 리전과 리소스(CPU, 메모리 등) 같은 클라우드 특화 정보로 라벨과 어노테이션을 추가한다.
3. 노드의 호스트네임과 네트워크 주소를 얻는다.
4. 노드의 상태를 검사한다. 노드가 응답하지 않으면 이 컨트롤러는 클라우드 제공자의 API를 사용해 서버가 비활성화/삭제/종료됐는지 확인한다. 노드가 클라우드에서 제거된 경우, 컨트롤러는 Kubernetes 클러스터에서 Node 객체를 제거한다.

일부 클라우드 제공자 구현은 이를 노드 컨트롤러와 별개의 노드 수명주기 컨트롤러로 나누기도 한다.

[k8s-concepts-arhictecture-nodes]: https://kubernetes.io/docs/concepts/architecture/nodes/
