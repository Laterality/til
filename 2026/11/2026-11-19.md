## 클러스터 아키텍처

### 클라우드 컨트롤러 매니저

#### 인가(Authorization)

##### 기타

클라우드 컨트롤러 매니저의 핵심 구현체는 Event 객체 생성을 위한 접근과 보안 작업을 위해 ServiceAccount 생성을 필요로 한다.

`v1/Event`: 

- create
- patch
- update

`v1/ServiceAccount`:

- create

클라우드 컨트롤러 매니저를 위한 [RBAC][k8s-reference-access-authn-authz-rbac] ClusterRole은 다음과 같이 생겼다:

```yaml
apiVersion: rbac.authorization.k8s.io/v1
kind: ClusterRole
metadata:
  name: cloud-controller-manager
rules:
- apiGroups:
  - ""
  resources:
  - events
  verbs:
  - create
  - patch
  - update
- apiGroups:
  - ""
  resources:
  - nodes
  verbs:
  - '*'
- apiGroups:
  - ""
  resources:
  - nodes/status
  verbs:
  - patch
- apiGroups:
  - ""
  resources:
  - services
  verbs:
  - list
  - watch
- apiGroups:
  - ""
  resources:
  - services/status
  verbs:
  - patch
  - update
- apiGroups:
  - ""
  resources:
  - serviceaccounts
  verbs:
  - create
- apiGroups:
  - ""
  resources:
  - persistentvolumes
  verbs:
  - get
  - list
  - update
  - watch
```

[k8s-reference-access-authn-authz-rbac]: https://kubernetes.io/docs/reference/access-authn-authz/rbac/
